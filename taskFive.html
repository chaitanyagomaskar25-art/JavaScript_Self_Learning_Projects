JavaScript Operators

Complete Guide with Examples and Outputs

Operator: An operator is a special symbol used to perform operations on one or more operands (values).

Types of Operators in JavaScript:

1. Arithmetic Operators

Used to perform mathematical calculations.

Operator Description Example Result
+Addition5 + 38
-Subtraction10 - 46
*Multiplication6 × 318
/Division12 / 34
%Modulus10 % 31
**Exponentiation2 ** 38
let a = 10;
let b = 3;

console.log(a + b);
console.log(a % b);
console.log(a ** b);

4. Logical Operators

Used to combine multiple conditions.

OperatorMeaningExampleOutput
&&ANDtrue && falsefalse
||ORtrue || falsetrue
!NOT!truefalse
let x = 10;
let y = 5;

console.log(x > 0 && y > 0);
console.log(x > 0 || y < 0);
console.log(!(x > 0));

5. Ternary Operator

Short-hand alternative of if-else.

condition ? value_if_true : value_if_false
        
let age = 18;
let result = age >= 18 ? "Adult" : "Minor";
console.log(result);
✔ If condition is true → first value is returned
✖ If false → second value is returned
