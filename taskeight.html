What is a String?

A string is a sequence of characters used to store and manipulate text in JavaScript. Strings are written inside quotes and are immutable. 

let name = "Chaitanya";
let greeting = 'Hello';
let message = `Welcome`;

Common String Methods

Method Description Example
length Returns string length "Hello".length → 5
toUpperCase() Converts to uppercase "hi".toUpperCase()
slice() Extract part of string "Hello".slice(1,4)
replace() Replace characters "Hi".replace("i","ello")
split() Convert string to array "a b".split(" ")
