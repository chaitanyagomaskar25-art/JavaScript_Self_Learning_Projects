Javascript Scope

Mastering variable visibility and memory lifespans

🌐

Global Scope

The highest level. Variables declared here are accessible from any function, block, or nested logic.

const zone = "Earth";

function check() {
    console.log(zone); // Works!
}
🔒

Function Scope

Each function creates its own sandbox. Variables defined inside cannot leak to the outside world.

function vault() {
    let code = "9901";
}

// console.log(code); // Error
📦

Block Scope

The { } boundaries. Restricted to loops and if-statements using let and const.

if (true) {
    let item = "Shield";
    var leak = "Water";
}
// console.log(item); // Error

Scope Cheat Sheet

Keyword Scope Type Re-assignable Hoisting
var Function Yes Yes
