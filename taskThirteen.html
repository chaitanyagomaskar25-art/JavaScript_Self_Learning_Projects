JavaScript Date & Date Object

1. What is Date?

The Date Object is a core JavaScript API used to manage temporal data. It tracks time by calculating the number of milliseconds elapsed since the Unix Epoch (January 1, 1970).

It acts as a multi-dimensional container for:

Calendar (Year, Month, Day)
Chronology (Hours, Mins, Secs)
Precision (Milliseconds)
Logic (Timezone Offsets)

2. Creating Date Objects

Different ways to create date objects:

Current Date and Time

let now = new Date(); console.log(now); // e.g., Tue Jan 20 2026 15:30:12 GMT+0000

Specific Date

let birthday = new Date("2000-05-15"); console.log(birthday); // Mon May 15 2000 00:00:00

Using Year, Month, Day, etc.

let examDate = new Date(2026, 0, 20, 10, 30, 0); // year, month (0-based), day, hours, minutes, seconds console.log(examDate);

Note: Month starts from 0 → January = 0, December = 11

3. Getting Date Components

You can get parts of the date using getter methods:

let now = new Date(); now.getFullYear(); // 2026 now.getMonth(); // 0 → January now.getDate(); // 20 → day of month now.getDay(); // 2 → day of week (0 = Sunday) now.getHours(); // 15 now.getTime(); // milliseconds since Jan 1, 1970

4. Setting Date Components

You can change parts of a date using setter methods:

let myDate = new Date(); myDate.setFullYear(2025); myDate.setMonth(5); // June (0-based) myDate.setDate(10); myDate.setHours(14); console.log(myDate);

5. Formatting Date

let now = new Date(); now.toDateString(); // Tue Jan 20 2026 now.toTimeString(); // 15:30:12 GMT+0000 now.toLocaleDateString(); // 1/20/2026 now.toLocaleTimeString(); // 15:30:12

6. Example: Display Date in HTML

You can show the current date on a webpage:

<p id="currentDate"></p> <script> let now = new Date(); document.getElementById("currentDate").innerText = "Today is: " + now.toDateString(); </script>

7. Summary Table

Method Description
new Date() Create current date & time
new Date("YYYY-MM-DD") Create specific date
getFullYear() Get year
getMonth() Get month (0–11)
getDate() Get day of month
getDay() Get day of week (0–6)
getHours() Get hours
getMinutes() Get minutes
getSeconds() Get seconds
getTime() Milliseconds since Jan 1, 1970
setFullYear(), setMonth(), setDate() Change date components
toDateString() Readable date string
toTimeString() Readable time string

8. Quick Tips

01.

Months are 0-indexed: January is 0 and December is 11.

02.

Use getTime() for high-precision date comparisons and math.

03.

The Date object is mutable: changing a component updates the original object.
