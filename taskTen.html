JavaScript Functions - Reusable Logic

1. What is a Function?

A function is a reusable block of code designed to perform a specific task. Instead of writing the same logic multiple times, we define it once and use it whenever needed.

function greet() { console.log("Hello!"); } greet();

Types of Functions

1. Function Declaration

A normal function defined using the function keyword.

function greet() { console.log("Hello"); }

2. Function Expression

A function stored inside a variable.

let greet = function() { console.log("Hello"); };

3. Arrow Function

A short and modern way to write functions (introduced in ES6).

const greet = () => { console.log("Hello"); };

4. Anonymous Function

A function without a name.

setTimeout(function() { console.log("Hello"); }, 1000);

5. Named Function

A function that has its own name.

function showMessage() { console.log("Welcome"); }

6. Parameterized Function

A function that accepts parameters (inputs).

function add(a, b) { console.log(a + b); }

7. Return Value

Returns a value using the return keyword.

function square(n) { return n * n; }

8. IIFE

A function that runs immediately after creation.

(function() { console.log("Runs immediately"); })();

9. Callback Function

A function passed as an argument to another function.

function greet(name, callback) { callback(); }

10. Constructor

Used to create objects using the 'this' keyword.

function Person(n) { this.name = n; }

Parameters vs Arguments

Parameters are placeholders in the definition, while Arguments are the actual values you pass.

function greet(name) { // name is a parameter console.log("Hello " + name); } greet("Alice"); // "Alice" is an argument
