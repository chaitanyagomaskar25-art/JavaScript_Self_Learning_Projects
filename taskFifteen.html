JavaScript Set and Map

1. What is Set?

A Set is a JavaScript object that stores only unique values. Duplicate values are automatically removed. 

let numbers = new Set([1, 2, 3, 2, 1]);
console.log(numbers);
// Output: {1, 2, 3}

2. Set Creation

let mySet = new Set();

let fruits = new Set(["Apple", "Banana", "Apple", "Mango"]);

3. Why Set is Used?

  • To store unique values
  • To remove duplicate data efficiently
  • Fast membership checking (searching)

4. Set Methods

MethodDescription
add(value)Add value
delete(value)Remove value
has(value)Check value exists
sizeTotal values count
clear()Remove all values
✨ Set is best for removing duplicate values from arrays

5. What is Map?

A Map stores data in key–value pairs. Unlike a standard object, keys in a Map can be of any data type.

Conceptual Structure:
"name" → Rahul
"age" → 21

6. Map Creation & Methods

let student = new Map();

student.set("name", "Amit");
student.set("age", 20);
console.log(student.get("name")); // Amit
MethodDescription
set(key, value)Add or update value
get(key)Get value by key
has(key)Check if key exists
delete(key)Remove entry by key
sizeTotal entries count
🚀 Map = High-performance key → value storage
