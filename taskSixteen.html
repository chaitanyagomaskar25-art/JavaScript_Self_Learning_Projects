🔁 JavaScript Iteration

A comprehensive guide to modern array and object traversal.

What is Iteration?

Iteration is the process of executing a block of code repeatedly for each item in a collection. It is the foundation of data processing in modern web development. 

let numbers = [1, 2, 3, 4];

1. forEach()

Ideal for executing side effects (like updating the DOM or logging data). It does not create a new array or return a value. 

let nums = [1, 2, 3];

nums.forEach((num) => {
  console.log("Current item:", num);
});
 Best for: Logging & DOM Updates

2. for...of

The most readable way to loop through iterable objects (Arrays, Strings, Sets). It provides a clean syntax without needing a callback function. 

let fruits = ["apple", "banana", "mango"];

for (let fruit of fruits) {
  console.log(fruit);
}
 Best for: Readability

3. for...in

Designed specifically for objects. It iterates over the enumerable property keys rather than the values themselves. 

let user = {
  name: "Chaitanya",
  age: 22,
  city: "Hyderabad"
};

for (let key in user) {
  console.log(`${key}: ${user[key]}`);
}
 Note: Avoid using for...in with Arrays

4. map()

A powerful transformation tool. It creates a brand-new array by applying a function to every element of the original array. 

let numbers = [1, 2, 3, 4];

let doubled = numbers.map(num => num * 2);

console.log(doubled); // [2, 4, 6, 8]
 Best for: Data Transformation

5. filter()

The primary tool for data selection. It returns a new array containing only the elements that pass a specific logical test. 

let numbers = [1, 2, 3, 4, 5, 6];

let evenNumbers = numbers.filter(num => num % 2 === 0);

console.log(evenNumbers); // [2, 4, 6]
 Best for: Searching & Filtering
