Mastering JavaScript Objects

1. What is an Object?

An Object is a standalone entity that holds data in key: value pairs. Think of it as a collection of variables (properties) and functions (methods) wrapped into one package.

  • Properties: The characteristics of the object (e.g., color, size).
  • Methods: The actions the object can perform (e.g., run, stop).

2. Object Creation

There are three primary ways to initialize an object in JavaScript:

A. Object Literal (Most Common)

const person = {
    firstName: "Chaitanya",
    lastName: "Kumar",
    age: 25
};

B. Using the new Object() Keyword

const car = new Object();
car.brand = "Tesla";
car.model = "Model 3";

C. Constructor Function

function User(name, role) {
    this.name = name;
    this.role = role;
}
const admin = new User("Amit", "Admin");

3. Properties & Methods

Access values using Dot notation or Bracket notation.

person.firstName; // Dot Notation
person["firstName"]; // Bracket Notation

A Method is a function stored as an object property.

const player = { name: "Virat", score: 100, celebrate: function() { return this.name + " is celebrating!"; } };
