🚀 JavaScript Basics Practice Projects

This repository contains small projects and exercises built while learning core JavaScript concepts.
The goal of these projects is to strengthen fundamentals and improve logical thinking.

📚 Concepts Covered

Functions

Objects

Arrays

Conditional statements

Loops

Basic input validation

String and number methods

🧠 Projects Included
🔹 Counter Application

A simple interactive counter that increases values using button clicks.
Demonstrates state management and event listeners.

🔹 Character Counter

Counts characters in a textarea in real time using the input event.

🔹 Number Validation

Validates user input to ensure only positive numbers are accepted.
Uses parseInt() and isNaN() for validation logic.

🔹 Object & Function Practice

Small logic-based programs using:

Return values
