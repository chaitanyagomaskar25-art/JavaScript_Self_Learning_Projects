JavaScript Array Guide

1. What is an Array?

Definition

An Array is a specialized object designed to store a collection of multiple values under a single variable name. Unlike standard variables, arrays are ordered and dynamically sized, allowing you to manage lists of data efficiently.

💡 Key Rule: Arrays use Zero-Based Indexing—the first item is always [0]. 
// Array creation
let fruits = ["Apple", "Banana", "Mango"];
let numbers = new Array(1, 2, 3, 4, 5);

// Access elements
console.log(fruits[0]); // Apple
console.log(fruits[fruits.length - 1]); // Mango

5. Multi-dimensional Arrays

Arrays containing other arrays (nested data):

let matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
];
console.log(matrix[1][2]); // 6 (Row index 1, Col index 2)

6. Technical Summary

Indexing Arrays are 0-indexed. The length is max_index + 1.
Memory Dynamically sized. Modified via push() or splice().
Pure Functions map() and filter() return new arrays (Immutable).
Search Use includes() for existence or find() for complex logic.
