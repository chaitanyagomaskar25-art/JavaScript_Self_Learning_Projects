Math Object

OBJECT REFERENCE

The Math object is a built-in property that allows you to perform mathematical tasks on numbers. Unlike other objects, it has no constructor; all properties and methods are static.

Essential Methods

Method Operation Result Example
Math.sqrt(16)Square Root4
Math.pow(2, 3)Power (Base, Exp)8
Math.random()Random (0 to 1)0.823...
Math.round(4.5)Round Nearest5

Regular Expressions

PATTERN MATCHING

Regular expressions are patterns used to match character combinations in strings. In JavaScript, regular expressions are also objects.

Common Patterns

SymbolMatches
\dDigits (0-9)
\wAlphanumeric
\sWhitespace
[a-z]Lowercase Range
^Start of String
$End of String

RegExp Flags

  • g (Global): Don't stop at first match
  • i (Ignore Case): Case-insensitive search
  • m (Multiline): Search across line breaks

Methods

// Using .test()
let pattern = /hello/i;
pattern.test("Hello World"); // true

// Using .replace()
"Blue Whale".replace(/Blue/, "Red");

Secure Password Logic

A typical secure password requires specific lookahead assertions (?=...) to verify complexity without consuming characters.

/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*?&])[A-Za-z\d@$!%*?&]{8,}$/
• Minimum 8 characters
• 1 Uppercase & 1 Lowercase
• 1 Number & 1 Special Char

Password Strength

❌ At least one lowercase

❌ At least one uppercase

❌ At least one number

❌ At least one special character

❌ Minimum 8 characters
