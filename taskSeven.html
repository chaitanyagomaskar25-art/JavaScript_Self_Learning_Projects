🚀 JavaScript Loops, Break & Continue

Loops are used to repeat a block of code until a condition becomes false. JavaScript provides multiple looping techniques for different situations.

Loop Description Basic Syntax
for loop Used when you know **how many times** you want to repeat a block of code. 
for(initialization; condition; increment/decrement){
    // code to execute
}
while loop Used when you want to repeat a block of code **while a condition is true**. 
while(condition){
    // code to execute
}
do-while loop Similar to while, but **executes the code at least once** before checking the condition. 
do {
    // code to execute
} while(condition);

Examples:

// for loop
for(let i = 1; i <= 5; i++){
    console.log("For loop iteration:", i);
}

// while loop
let j = 1;
while(j <= 5){
    console.log("While loop iteration:", j);
    j++;
}

// do-while loop
let k = 1;
do {
    console.log("Do-while loop iteration:", k);
    k++;
} while(k <= 5);

Break and Continue in JavaScript

Break: Used to **exit a loop immediately**.

Continue: Used to **skip the current iteration** and move to the next iteration.

Keyword Use Example Output
break Exit the loop completely when a condition is met 
for(let i=1; i<=5; i++){
    if(i==3){ break};
    else{console.log(i)};
}

  1. Print Multiplication Table

function tableFor() {
    for(let i=1; i<=10; i++){
        console.log(`${num} x ${i} = ${num*i}\n`);
    }

      • let num = 10
function tableWhile() {
    let i = 1;
    while(i <= 10){
        console.log(`${num} x ${i} = ${num*i}\n`);
        i++;
    }
}

      • let num = 10
function tableDoWhile() {
    let i = 1;

    } while(i <= 10);

  2. Factorial of a Number




    • for loop
      • let num = 5;
function factFor() {
    if(num < 0){
        console.log("Factorial not defined for negative numbers!");
        return;
    }
    let fact = 1;
    for(let i=1; i<=num; i++){
        fact *= i;
    }
    console.log(`Factorial of ${num} (For Loop) = ${fact}`);
}
    • while loop
      • let num = 5;
function factWhile() {
    if(num < 0){
        console.log("Factorial not defined for negative numbers!");
        return;
    }
    let fact = 1, i = 1;
    while(i <= num){
        fact *= i;
        i++;
    }
    console.log(`Factorial of ${num} (While Loop) = ${fact}`);
}
    • Do-while loop
      • let num = 8; 
function factDoWhile() {
    if(num < 0){
        console.log("Factorial not defined for negative numbers!");
        return;
    }
    let fact = 1, i = 1;
    if(num === 0){
        fact = 1; // factorial of 0
    } else {
        do {
            fact *= i;
            i++;
        } while(i <= num);
    }
    console.log(Factorial of ${num} (Do-While Loop) = ${fact}`);
}
