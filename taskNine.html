JavaScript Numbers & Number Methods

Complete beginner-friendly explanation with examples

What is a Number?

In JavaScript, Number is a data type used to store numeric values. JavaScript does not have separate integer or float types — all numbers are treated as one type. 

let age = 20;
let price = 99.99;
let temperature = -5;

Important Concept

When input is taken from the user using input or prompt, JavaScript stores the value as a string. 

let num = "10";

console.log(num + 5); // 105 (string addition)

Common Number Methods

let num = 10.5678;

num.toFixed(2);          // "10.57"
num.toString();          // "10"
isNaN("abc");            // true
Number.isInteger(10);    // true

Math Methods

Math.round(4.6);   // 5
Math.floor(4.9);   // 4
Math.ceil(4.1);    // 5
Math.random();     // 0 to 1
Math.max(10,20);   // 20
Math.min(5,2);     // 2

parseInt()

Converts a value into a whole number (integer). 

parseInt("10");      // 10
parseInt("10.5");    // 10
parseInt("25px");    // 25
parseInt("abc");     // NaN

parseFloat()

Converts a value into a decimal number. 

parseFloat("10.5");   
parseFloat("25.75px");

Number()

Converts a value strictly into a number. If the value contains text, it returns NaN. 

Number("10");     // 10
Number("10.5");   // 10.5
Number("10px");   // NaN

Difference Between Conversions

Value parseInt parseFloat Number
"10" 10 10 10
"10.8" 10 10.8 10.8
"10px" 10 10 NaN

Real Example

let a = "10";
let b = "20";

let sum = parseInt(a) + parseInt(b);

console.log(sum); // 30
